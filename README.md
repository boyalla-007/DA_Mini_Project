## 📌 Project Overview
Historically, it was assumed that as a country's Gross Domestic Product (GDP) increases, the consumption of non-essential goods like soft drinks would rise in tandem. However, recent trends suggest a **"saturation story."** 

This project uses Python to perform Exploratory Data Analysis (EDA) and hypothesis testing to evaluate this saturation curve across three distinct economies from 2000 to 2023:
* **India 🇮🇳:** A developing economy (rising GDP, rising consumption).
* **United States 🇺🇸:** A mature economy (rising GDP, but past its peak soda consumption).
* **United Kingdom 🇬🇧:** A mature economy with a sharp, policy-driven decline (due to the 2018 Soft Drinks Industry Levy).

## 📊 Key Objectives
1. Collect and preprocess a country-year panel dataset (2000–2023).
2. Visualize the trajectory of GDP per capita alongside per capita fizzy drink consumption.
3. Test the "saturation hypothesis" using OLS regression and Pearson correlation to see if higher-income countries exhibit a decoupling of GDP and soda consumption.

## 🚀 Key Findings
1. **India:** Shows a strong positive relationship ($\beta$ = 0.85, $p < 0.05$). As the economy grows, discretionary spending on beverages increases.
2. **United States:** Shows market saturation with a negative relationship ($\beta$ = -0.12, $p < 0.05$). Consumption is slowly declining despite continued GDP growth post-1990s.
3. **United Kingdom:** Demonstrates a sharp decoupling ($\beta$ = -0.34, $p < 0.05$) largely driven by the 2018 Sugar Tax, which caused an approximate 19% drop in average per capita consumption.
